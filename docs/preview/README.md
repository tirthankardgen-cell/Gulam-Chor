# Preview captures

These are actual Chrome screenshots of the working local preview. The illustrations are original SVG colour studies; the final generated paintings are deliberately deferred to the image handoff in `art-direction/`.

- `landing.webp`: single hero at 1440×900.
- `table.webp`: four-seat game at 1440×900.
- `landing-mobile.webp`: the hero at 390×844.
- `table-mobile.webp`: the six-seat table at 390×844.

Cards, players, labels, buttons, and game results are real application UI. The captured hands are one random preview deal, not a fixed or rigged starting layout.
